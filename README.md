# JAVA-05-12-2025

Ce repository contient le code développé sur les séances de Java de la semaine du 1er décembre

## Build & Run

Repo sur Maven donc:

```
git clone https://github.com/remabd/JAVA-05-12-2025.git
cd JAVA-05-12-2025
mvn clean install
mvn compile
mvn exec mvn exec:java -Dexec.mainClass="com.test.app.App"

```
